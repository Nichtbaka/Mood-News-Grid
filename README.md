Mood News Grid
Mood News Grid — это веб-приложение для агрегации и адаптивного чтения новостей. Сервис считывает актуальные RSS-ленты, а затем с помощью языковой модели (LLM) переписывает новости в выбранном эмоциональном стиле (Радостно, Грустно, Иронично, Драматично) с гарантированным сохранением исходных фактов.

Описание функциональности
Приложение выполняет автоматический сбор новостей путем регулярного парсинга RSS-лент с последующей очисткой текста от HTML-тегов, спецсимволов и технического мусора.

Интерфейс пользователя реализован в виде двухпанельного ридера (боковое меню и центральная область чтения). Боковое меню поддерживает возможность сворачивания для комфортной работы на мобильных устройствах и планшетах. Размер шрифтов и элементов управления автоматически адаптируется под разрешение экрана. При смене эмоционального режима меняется цветовая гамма приложения и фоновое свечение. Полосы прокрутки визуально скрыты, но навигация с помощью мыши и сенсорного ввода полностью сохранена.

Для каждой новости доступен режим сравнения, позволяющий одновременно видеть оригинальный текст и его адаптацию под выбранное настроение.

Архитектура и логика работы
Приложение построено по классической клиент-серверной схеме.

Взаимодействие компонентов происходит следующим образом:

При старте Go-сервер запрашивает данные из RSS-каналов, парсит XML-структуру, очищает заголовок и описание, после чего сохраняет полученные статьи во внутреннем хранилище.

После загрузки пользовательского интерфейса React-приложение делает запрос к эндпоинту /api/news и отображает полученный список новостей в боковом меню.

При выборе конкретной новости и эмоционального тона (например, "Иронично") фронтенд отправляет запрос к /api/rewrite, передавая идентификатор статьи и выбранный режим.

Бэкенд извлекает из памяти оригинальный текст статьи, подставляет его в системный промпт с правилами трансформации и передает запрос в сервис LLM. Полученный ответ отправляется на фронтенд для отображения рядом с оригиналом.

Хранение данных
В текущей реализации приложения используется хранение данных в оперативной памяти (In-Memory Storage) на стороне Go-бэкенда.

Все статьи при парсинге преобразуются в структуру Article и получают уникальный идентификатор UUID v4. Данные хранятся в оперативной памяти процесса Go. Это обеспечивает минимальное время отклика API и исключает необходимость развертывания внешней базы данных при локальном запуске. При этом архитектура бэкенда предусматривает слой репозитория, что позволяет при необходимости быстро подключить внешнюю СУБД, такую как PostgreSQL или Redis.

Использование AI и контроль фактов
Переписывание новостей выполняется с использованием языковых моделей через API, совместимый с OpenAI (OpenRouter или прямой API OpenAI).

Для предотвращения генерации ложных сведений и искажения информации применяется система строгих ограничений в системном промпте. Модели явно задается роль редактора новостей, обязанного строго сохранять фактическую точность.

В правилах генерации установлены следующие ограничения:

Запрещено добавлять события, факты, имена, даты или числовые показатели, отсутствующие в оригинальном тексте.

Запрещено выдумывать контекст или изменять суть происходящего.

Все упоминания людей, компаний, географических названий и точных данных должны переноситься из оригинала без изменений.

Изменениям подлежат исключительно стилистика, эмоциональная окраска и используемая лексика.

Если API-ключ нейросети не задан или внешняя служба недоступна, приложение переходит в режим эмуляции (Mock mode) и возвращает исходный текст с уведомлением, предотвращая сбой в работе сервера.

Стек технологий
Backend: Go 1.22+, библиотека gofeed для парсинга RSS, пакет uuid для генерации идентификаторов, стандартный модуль net/http.

Frontend: React 18, Vite, Tailwind CSS 3, PostCSS.

AI Integration: OpenRouter / OpenAI REST API.

Инструкция по запуску
Для запуска приложения требуются Go версии 1.22 или выше и Node.js версии 18 или выше.

Автоматический запуск в Windows
В корневой директории проекта выполните команду:

DOS
.\run.bat
Ручной запуск
Запуск серверной части (Go):

Перейдите в директорию бэкенда, при необходимости установите переменную окружения LLM_API_KEY с вашим ключом API, загрузите зависимости и запустите сервер:

Bash
cd backend
go mod tidy
go run main.go
Сервер бэкенда будет доступен по адресу http://localhost:8080.

Запуск клиентской части (React):

В отдельном окне терминала перейдите в директорию фронтенда, установите зависимости и запустите сервер разработки:

Bash
cd frontend
npm install
npm run dev
Интерфейс приложения будет доступен в браузере по адресу http://localhost:5173.

API Эндпоинты
GET /api/news — возвращает список всех загруженных новостей из памяти сервера.

POST /api/rewrite — принимает JSON с параметрами article_id и mood, возвращая адаптированный текст новости.
